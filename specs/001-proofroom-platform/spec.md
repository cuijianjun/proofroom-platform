# Feature Specification: 多工作室摄影选片平台
**Feature Branch**: `agent/proofroom-local-main`
**Created**: 2026-11-14
**Status**: Ready for implementation · v1.1 UX合并基线
**Input**: 按 ../需求规格与实施方案.md 新建独立工程，本地完整覆盖摄影师与客户业务。

## User Scenarios & Testing
### User Story 1 - 创建与管理工作室 (Priority: P1)
摄影师无需支付创建工作室，按Owner/Admin/Member协作、切换与退出；平台支持只能只读代看。
**Independent Test**: 两工作室与多成员完成注册、邀请、角色、禁用和会话撤销，跨租户读写/媒体拒绝。
**Acceptance Scenarios**: 普通成员不能改Owner/配置；所有权转移二次确认；移除后下一请求撤权；未保存切换有提示。
### User Story 2 - 展示、问卷与咨询 (Priority: P1)
独立公开页、作品、套餐FAQ、动态八题问卷、十五图、版本草稿、私密回执。
**Independent Test**: 自定义配置后客户咨询，不创建项目；旧版本409保输入；重放同请求返回同回执。
**Acceptance Scenarios**: 固定身份题不可删除；第十六参考拒绝；回执不可凭咨询ID读取；旧答卷随版本冻结。
### User Story 3 - 接单、项目与预约 (Priority: P1)
摄影师咨询确认/手工建单，一次冻结约定并占时段；改期冲突保旧档；取消与恢复保阶段。
**Independent Test**: 并发确认仅一项目、并发抢档仅一成功；项目入口、需求卡和列表一致。
**Acceptance Scenarios**: 无邮箱可建单；同键异内容拒绝；列表滚动返回恢复；历史恢复不续期。
### User Story 4 - 原片和选片 (Priority: P1)
项目内原生文件选择、逐文件恢复、持久批次、压缩预览就绪自动开放；客户PIN、星级颜色备注、超选、提交/改选。
**Independent Test**: 4原片整批→P2，客户选3并备注→P3；坏图/丢响应/重启不会提前推进或重复照片。
**Acceptance Scenarios**: 所选备注变化需重提，未选备注不误报；只读预览不能发客户身份或下载。
### User Story 5 - 精修、交付与期限 (Priority: P1)
精修自动/人工对应齐套后自动P4；单图和全部/原片/精修源文件ZIP；归档、续期与补片。
**Independent Test**: 2自动1错名人工→自动交付，源SHA256/ZIP CRC一致；补片含新文件不续期；十次下载无次数门禁。
**Acceptance Scenarios**: 缺件/重复/歧义/旧版本阻断；过期Range同样拒绝；续期幂等。
### User Story 6 - 完整交互与运维 (Priority: P1)
全部UI/CU操作、中文五态、灯箱、图库、账号安全、备份恢复与独立运行。
**Independent Test**: 手机320/390/393与1280桌面完整单；每个编号保存取消/错误可恢复；隔离备份恢复可登录和下载。
**Acceptance Scenarios**: 错误不假零、失败保输入；原文件不作浏览预览；浏览器模拟与原生系统选择器、微信真机分别记录。

### Edge Cases
角色撤销、租户暂停/只读、同键异内容、预约竞争、问卷CAS、坏图/重启/迟到回调、清单改变、对应冲突、过期与补片、两日历月边界、离线/截断JSON/429/剪贴板失败均不可跳过。

## Requirements
### Functional Requirements
正本第3～7、10～12、15、19章为规范性引用；以下映射不删减其逐条验收：
- **L-FR-01**: 每个工作室独立公开主页，顺序展示作品、套餐、FAQ、问卷和意向档期。验收：相同公开版本对不同访客一致；无其他客户答案、项目信息或能力 token。
- **L-FR-02**: 默认八题模板、人民币价格文字、中文 FAQ；支持拍摄类型“其他”说明。验收：固定身份项完整；不要求客户填写邮箱或完整手机号。
- **L-FR-03**: 售前表达日期/具体时段意向，允许“日期可商量”。验收：不因浏览或提交咨询占用档期；兼容旧文本日期。
- **L-FR-04**: 提交只生成咨询，字段白名单、校验、蜜罐、限流；返回回执。验收：不创建客户拍摄项目、图库或发送自动通知；PIN 四位数字；作品 ID 属于当前公开配置。
- **L-FR-05**: 待确认/确认中/已确认/已忽略咨询；可能重复提示。验收：不按后四位自动合并客户；已确认不回退；重复线索可独立保留。
- **L-FR-06**: 统一登录、待办和咨询入口、项目列表、复制身份确认、接单双重确认。验收：未登录与权限不足不能读写；主操作显示目标客户。
- **L-FR-07**: 一次确认生成项目、图库关联、需求快照、专属入口、咨询关联和微信文案。验收：用户不重复录入答案；本单套餐、张数、约定和预约在本次确认冻结。
- **L-FR-08**: 确认、手工建单、重试均幂等，失败可恢复。验收：并发仅一个项目和对应图库；不出现已确认但无项目；同幂等键不同内容拒绝。
- **L-FR-09**: 不可猜项目 token + 四位 PIN，一次通过记住三十天。验收：PIN 不用于定位；错误五次受限；无效/未激活链接统一不可见；不同项目 cookie 不通用。
- **L-FR-10**: 选片与备注单一事实来源，详情显示最新数据。验收：不复制另一套可编辑清单；未知/失败不冒充零或“无变化”。
- **L-FR-11**: 全部原片和精修片分组交付；交付后客户只读。验收：原片为全部原片；归档未过期仍可下载；任何源下载均受服务端控制。
- **L-FR-12**: 手工新建、忽略、归档和受保护阶段纠正。验收：手工项目拥有同等链接/快照/图库；不得任意跳级绕过就绪校验。
- **L-FR-13**: 客户所有页面、图片操作、ZIP、错误和权限提示中文。验收：动态弹窗、浏览器业务提示、加载和只读状态同样覆盖，原始文件名除外。
- **L-FR-14**: 首次交付起三十天，过期服务端拒绝，次数不限。验收：无下载次数门禁、业务计数列或“已下载 N 次”；到期有微信续期引导。
- **L-FR-15**: 允许超选，派生已选/套餐/超出数，提示费用线下确认。验收：额度八张可选十二张并提交；不增加支付或营销邀请流程。
- **L-FR-16**: 项目内原片/精修批量上传、目标客户提示、逐文件状态与重试。验收：无需第二后台；HTTP 上传成功与预览就绪分别表示。
- **L-FR-17**: 服务端状态机、前置条件、相邻异常纠正、中文拒绝原因。验收：新项目不能用部分交付或手动按钮绕过严格匹配；历史兼容另行显式标识。
- **L-FR-18**: 顶部上下文、工作台状态筛选、搜索排序、待办优先。验收：用滚动加载替代旧分页按钮；列表无逐单读取照片及备注。
- **L-FR-19**: 项目详情固定客户条、概览/原片/清单/交付、上下文快捷操作。验收：写操作前识别目标；滚动后客户和分区上下文仍可见。
- **L-FR-20**: 客户空间按阶段显示下一步，需求卡/清单折叠，交付下载优先。验收：P1 明确等待原片；P4 首屏可见下载；交付后不再提供编辑选片。
- **L-FR-21**: 正常/空/加载/可恢复错误/只读五态，中文 429 和重试。验收：保留输入及已加载内容；不用原生 alert/confirm/prompt 承载关键业务。
- **L-FR-22**: 工作台、项目列表和“我的”职责清晰，状态来自一致规则。验收：卡片与详情指向同一项目任务；未读取实时选片时不伪造实时数量。
- **L-FR-23**: 咨询三类列表、完整答卷、确认/忽略/恢复和直达项目。验收：已确认直接进入项目；确认采用 URL 对应线索，不信任表单伪造 ID。
- **L-FR-24**: 触底追加、下拉刷新、筛选重置、返回恢复窗口与滚动。验收：并发加载去重；刷新失败保原内容；表单/上传不误触下拉刷新。
- **L-FR-25**: 串行或受控并发批量上传；失败重试、离开保护、归档限制。验收：成功项不重传；无效/空文件拒绝；精修仅 P3/P4 补片；归档禁止上传。
- **L-FR-26**: 保留旧 P3 就绪下载兼容、P4 开始期限的业务语义。验收：新项目未完成批次不下载；回退到 P1/P2 关闭；回退和补片不延长期限。
- **L-FR-27**: 客户“我已选好”、当前完成摘要、改选后重新提交、摄影师只读预览。验收：清单/备注未知不可提交；预览不签发客户 cookie、不提供客户编辑和源下载。
- **L-FR-28**: 作品分组切换、仅一份作品选择区、默认示例、草稿与回改。验收：最大数采用最新十五张；旧自定义作品保留；示例明确标识、不冒用真实客户照片。
- **L-FR-29**: 单一业务 API 承接全部业务，所有前端只通过契约调用。验收：新目标为独立 Web 与 API；不依赖第二套 PicPeak 业务服务或自调用 API key。
- **L-FR-30**: 统一元数据主库，事务一致性，文件副作用可补偿。验收：不建另一份客户选片库；数据库提交与对象存储失败分别可恢复。
- **L-FR-31**: 统一工作人员身份、退出、禁用、强制改密和启用后的 MFA。验收：工作台与媒体权限不可绕过；管理员凭证不能当作客户 PIN 凭证。
- **L-FR-32**: 提供可回退迁移设计，旧源数据只读保护，重复导入幂等。验收：如后续执行迁移，保留项目、链接、快照、清单、备注、期限和媒体摘要；冲突拒绝。
- **L-FR-33**: 备份/恢复含业务表、配置、身份必要密钥与媒体清单。验收：恢复副本可登录、访问项目和下载；不自动触发消息或外部副作用。
- **L-FR-34**: 问卷新增/删除/编辑/排序，简答、长文本、单选、多选及作品选择。验收：称呼与联系方式固定存在且必填；作品题保持特殊类型，可删除。
- **L-FR-35**: 稳定问题 ID、版本 CAS、严格 schema 和限长。验收：2～30 题；题干 1～120 字；提示≤200；选项 1～20、每项 1～100；ID/选项不重复。
- **L-FR-36**: 动态公开表单、版本校验、草稿绑定版本、新旧答案迁移提示。验收：旧页提交返回 409 保输入；删除作品题不残留控件；仅未变化问题可沿用旧答案。
- **L-FR-37**: 提交时题目定义与答案快照，按提交版本显示回执和需求卡。验收：改题型、删题、改套餐不回写旧记录；不将用户文本解释为 HTML。
- **L-FR-38**: 问卷管理复用工作室登录、来源校验、中文控件和未保存保护。验收：取消删除不生效；保存失败、过期版本均保留编辑。
- **L-FR-39**: 套餐/FAQ 增删改、排序、折叠、空态及版本保护。验收：历史需求快照不变；选填空字符串/末尾空行归一化。
- **L-FR-40**: 风格参考最多十五张；作品和图库只展示压缩图。验收：十五接受、十六拒绝；压缩失败不回退源图；历史保留安全公开图片引用。
- **L-FR-41**: 时段增改、开关、取消占用、确认独占、中国时区。验收：同时段可有多咨询但只能一个确认；重叠/过期/占用时段按规则拒绝。
- **L-FR-42**: 完整批次自动 P1→P2、客户提交 P2→P3、精修齐套 P3→P4。验收：批次期望/接收集合持久化；失败/缺件/降级不推进；迟到回调幂等；到期自动归档。
- **L-FR-43**: 行动中心、今日预约、需要处理/等待顾客/已交付、项目档案。验收：状态角标和筛选同源；不虚构收入；列表无逐项目媒体调用。
- **L-FR-44**: 忽略/归档满两个日历月后普通列表隐藏；历史搜索恢复可见。验收：不删数据库/照片；恢复可见不改变阶段和期限；不能以恢复列表代替续期。
- **L-FR-45**: 统一中文选择面板：手机底部、桌面对话框，键盘/焦点/取消完整。验收：动态问题、日期选择和必填可用；前端只维护一份表单状态。
- **L-FR-46**: 稳定套餐 ID、结构化精修额度、本单套餐/额度/特别约定快照。验收：意向不等于最终约定；确认可单独约定；旧项目不随公共套餐变化。
- **L-FR-47**: 稳定文件编号匹配、前后缀/扩展名兼容、异常人工对应。验收：缺失/重复/歧义阻止自动交付；映射带当前清单版本；旧项目兼容不得默猜。
- **L-FR-48**: 续期三十天，保链接/PIN/文件；归档续期回 P4。验收：按 max(当前时间, 原到期) 加三十天；重复请求只延长一次；过期版本 409。
- **L-FR-49**: 原子改期、取消预约、取消合作、恢复合作。验收：改期失败保旧档；取消释放占位；恢复不抢回旧档；客户看到合作已取消及联系入口。
- **L-FR-50**: 工作室资料和公开作品 CRUD、分组、排序、压缩上传、版本保护。验收：只由工作人员主动公开；去除 EXIF；不暴露私有图库或源文件；旧引用不误删。
- **L-FR-51**: 已选参考图在摘要、回执、线索和需求卡直接显示，可预览与回改。验收：不重复长 ID；粗略日期和具体时段未约定时正确提示；自定义题干保留。
- **L-FR-52**: 稳定提交键、内容校验、不可猜回执地址、刷新恢复。验收：重复请求同内容复用；不同内容拒绝；公开咨询 ID 不能读取答案；蜜罐无真实回执。
- **L-FR-53**: 图库清楚表达“选入精修”，显示已选数并直接提交/重新提交。验收：保留星级与颜色选择语义；同图不重计；不计精修的点赞/收藏不能混入清单。
- **L-FR-54**: 当前完成最小基线与改选差异；事件驱动 attention；准确交付阻断原因。验收：区分新增/移除/备注变化、缺图/处理/失败/对应冲突；不靠列表逐单读图。
- **L-FR-55**: 授权大预览、文件名复制、当前清单 CSV、上传缩略预览和恢复提示。验收：CSV 防公式注入；预览是压缩图；下载内容保持源字节；不声称无限后台续传。
- **L-FR-56**: 默认需要处理、未来拍摄合理排队、阶段主分区和阶段通知。验收：改选/异常优先；P4 交付优先；复制成功仅表示复制，不表示已通知客户。
- **L-FR-57**: 我的/配置/帮助聚合，套餐FAQ和问卷排序，预约历史折叠。验收：滚动加载保持；不新增钱包/营销统计；编辑状态可恢复。
- **L-FR-58**: 紧凑顶栏与吸顶 tab、统一间距、44px 触区、长文本和焦点。验收：手机/电脑无横溢；吸顶不遮字段、底部操作不遮按钮；滚动和键盘操作保留。

### Key Entities
工作人员/工作室/成员/邀请、客户/咨询/回执、拍摄订单/预约、图库/照片/选片/备注、批次/任务/对应/期限、配置版本/审计/备份。

## Success Criteria
### Measurable Outcomes
- SC-001: 全部58项本地业务要求、37项摄影师交互、9项客户交互逐项有结果与证据。
- SC-002: AT-01～39本地可执行部分通过；真机与生产另列外部验收，不以模拟代替。
- SC-003: 从咨询到交付完整单无需打开第二后台，所有下载与上传源字节一致。
- SC-004: 两工作室任何资源/成员/媒体交叉访问均拒绝；失败重试不重复建单/占档/续期。

## Assumptions
- 本期只本地开发，不接支付/营销，不迁移真实数据。
- 工作室默认Asia/Shanghai和人民币文字；保持中文业务语义。
- 设备与外部环境没有实测的部分保留明确边界，不阻塞可执行本地开发。

## v1.1 体验合并补充（规范性）
