03 / BEFORE WE MEET

你可能想问

拍摄前的小约定
Q

原片、精修和交付有什么区别？

浏览和选片使用压缩预览。最终交付下载的是摄影师上传的原片及精修源文件，不是网页缩略图。

精修张数按双方确认的套餐与约定，具体交付时间由摄影师与你沟通。

Q

可以改期吗？

可以先与摄影师沟通新的可用时段，确认后再改期。取消预约只释放时段，不会取消拍摄合作或删除照片。

Q

提交咨询后，时间就定下来了吗？

还没有。你选的是意向时段，摄影师确认接单后才会占用档期。是否接单、拍摄安排和费用，都会再与你确认。

DESIGN REVIEW / V1

让客户一眼看懂，少一点猜测

先看作品建立信任，再了解方案与答案，最后只填必要信息。原有信息和功能保留，用清楚的层级和按需展开降低负担。

  1. 工作室介绍不再霸占首屏

    首页约两行摘要；“了解摄影师”明确打开完整介绍，超长名称完整内容也能读取。

  2. 分类要看起来就能点

    有底色、边框、选中态、横向滑动提示，支持键盘方向键。完整分类列表解决长名称，不把几行长文当成按钮。

  3. 问与答同时可见

    每条问题下面直接显示答案。只有长内容需要“展开完整问答”，不把所有答案默认藏起来。

  4. 作品、套餐、时段，只选择一次

    参考选择跨分类保留；套餐点击后同步计划摘要和咨询表单。时段在弹层草选，确认才回填，关闭则保留原选择。

  5. 必填放前面，选填可展开

    保称呼、类型、微信和4位码；预算、时间说明、来源、在意与避免、地点等选填收进补充偏好。正式实现仍遵守工作室配置的必填规则、题目ID和顺序。

  6. 电脑和手机各用合适的空间

    电脑有计划摘要侧栏；手机两列作品、单列填写、底部主操作。摄影师电脑保侧栏，顶部不再有独立返回按钮；手机保胶囊返回。
