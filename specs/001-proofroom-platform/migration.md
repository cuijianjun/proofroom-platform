# 本地备份与独立恢复

租户备份由当前 Owner 在「帮助与数据」发起并下载，仅限自己发起的记录。只读工作室允许备份，暂停工作室不可用。口令12～200字符、仅内存输入；下载不是完成证明，需以浏览器文件记录并实际恢复核对。服务器24小时缓存不是长期备份。后台生成期间固定元数据与媒体引用，处理中图片阻止新快照，失败图片保留源文件及重试信息。公开作品的已消费上传临时源不入包，页面展示文件保留。

包使用带认证的AES-256-GCM，scrypt独立盐派生密钥；逐源文件SHA256并核对大小。解密认证完成后才解析元数据和建恢复库。备份含必要的本工作室客户链接、访问码哈希和Owner账号恢复资料，必须私密保管。其他成员不导出全站密码/MFA，恢复生成新临时密码强制改密；历史署名为禁用匿名身份。租户导出剥离平台权限，不含APP_SECRET、DB/S3凭据、其他租户、会话及缓存；本机全量命令另保留全站业务身份。

使用固定Node22运行，以下命令在仓库根执行，交互口令输入不回显。自动化使用`--passphrase-stdin`，从安全标准输入提供，不将口令写进命令参数或日志。

```sh
npm run backup -- full-export --output /安全目录/新的全量备份.prbackup
npm run backup -- restore --file /安全目录/工作室备份.prbackup --name rehearsal_20261115
```

恢复只允许本项目127.0.0.1/localhost:18432及全新`proofroom_restore_*`库；已有库/输出目录拒绝覆盖。默认输出`.local/restores/<随机编号>/`，权限0700，其中`runtime.env`与可能存在的`member-recovery.json`权限0600。新副本独立APP_SECRET重新封装受控访问资料，独立媒体前缀，不打印密钥、客户链接和密码。恢复包读取不会自动启动服务。启动前确认Web18188/API18189空闲，然后执行 `node scripts/local.mjs restore /绝对路径/恢复输出目录`。此入口显式将Web的API_ORIGIN指向副本18189，剥离Web的DB/S3/APP_SECRET，使用独立.next-restore构建目录。API/Worker携带MEDIA_NAMESPACE；后续新上传、预览重试、作品与ZIP/备份都写独立恢复前缀，不能回写原根。请用独立浏览器配置或隐私窗口核对副本，避免同主机不同端口共享cookie影响原工作台登录。停止仅使用该命令的终端Ctrl+C，不停止其他项目。

迁移前保留旧库、原媒体和当前程序版本。恢复后核对账号/MFA、咨询回执幂等、原客户链接/PIN、选片星色与原文备注、文件数量/SHA256和原到期日；不把恢复当作续期。若恢复被强行中断，输出目录中的私有`restore-state.json`记录本次独立库与媒体前缀；先确认恢复进程已结束，再由本机管理员仅清理该副本。普通失败会清理已尝试的对象/分段上传和新库；清理遇到存储或数据库故障时明确报待清理并保留记录。成功后自动删除该临时记录。包元数据上限128MiB，导出和读取使用同一边界，不另设隐藏行数上限。会话需重新登录，待接收上传需重选未接收文件，ZIP缓存需重新准备。所有核对通过后再单独授权切换；失败可继续使用原服务，无需反向覆盖数据库。SQL迁移按摘要校验且已应用文件不可改；不同迁移版本的包需用匹配程序恢复。生产跨机迁移、云S3、真实大批容量与设备验收不以本地演练代替。
